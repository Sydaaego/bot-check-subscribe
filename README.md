# Telegram Bot Template

Простой шаблон Telegram-бота на Python и `aiogram`.

## Что делает бот

- Отвечает на команду `/start`.
- Показывает приветственное сообщение с картинкой.
- Добавляет кнопку `Проверить подписку`.
- Проверяет, подписан ли пользователь на указанный Telegram-канал.
- Отправляет сообщение с результатом проверки.

## Требования

- Python 3.10 или новее
- Telegram Bot Token от [@BotFather](https://t.me/BotFather)
- Установленная библиотека `aiogram`

## Установка

1. Скачайте или скопируйте файлы проекта.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

```bash
pip install aiogram
```

## Настройка

Откройте файл `main2.py` и замените данные под свой проект:

```python
bot = Bot(token="ВАШ_ТОКЕН_БОТА")
```

Также замените username канала, подписку на который нужно проверять:

```python
chat_id='@your_channel'
```

Важно: бот должен быть добавлен в этот канал администратором, иначе он не сможет проверять подписку пользователей.

## Запуск

В терминале выполните команду:

```bash
python main2.py
```

После запуска откройте своего бота в Telegram и отправьте команду:

```text
/start
```

## Что можно изменить

- Текст приветствия.
- Картинку в стартовом сообщении.
- Текст кнопки.
- Username канала для проверки подписки.
- Сообщения для подписанных и неподписанных пользователей.

## Передача заказчику

Для работы заказчику нужны:

- файл `main2.py`;
- этот файл `README.md`;
- токен Telegram-бота;
- username канала, где бот будет проверять подписку.

Токен бота нельзя публиковать в открытом доступе. Если токен случайно был отправлен посторонним людям, его нужно перевыпустить через [@BotFather](https://t.me/BotFather).
